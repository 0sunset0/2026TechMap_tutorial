# 스크린샷 체크리스트

`.tutorial` 파일의 코드 없는 스텝 중, 실제 화면/결과물을 보여주면 이해에 도움이 되는 곳들을 정리한
목록입니다. 캡처가 끝나면 `Resources/`에 파일을 넣고, 각 스텝의 텍스트 뒤에 `@Image(source:alt:)`를
추가하면 됩니다.

      호출했을 때 iOS가 앱을 강제 종료하는 화면 (또는 콘솔 크래시 로그).
      alt: "카메라 권한 문구 없이 실행했을 때의 크래시 화면"
